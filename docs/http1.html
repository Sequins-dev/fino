fino:net/http1 — HTTP/1.1 server and client drivers.

H1ServerDriver.run() drives one accepted connection: pipelined keep-alive pump, OTel instrumentation, protocol-upgrade handoff, batched writev.

H1ClientDriver.send() serialises one Request and parses the Response on an already-connected reader/writer pair. DNS, TCP/TLS connect, redirect following and body wrapping are all handled by the caller (fetch.mts).
