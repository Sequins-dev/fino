http2

js/net/http2.mts

fino:net/http2 — public HTTP/2 module.

Currently exposes:

  • h2Available: whether libnghttp2 was found on this system
  • h2Version: library version string, or null if unavailable

The H2 server and client drivers are wired into fino:net/serve and fino:fetch automatically; applications do not import this module unless they need to check library availability.

Constants

export const h2Available: boolean

export const h2Version: string | null
