js/internal/globals/crypto.mts

fino:crypto — Web Crypto API.

Implements a useful subset of the W3C Web Cryptography API: crypto.getRandomValues(typedArray) crypto.randomUUID() crypto.subtle.digest(algorithm, data) crypto.subtle.sign(algorithm, key, data) crypto.subtle.verify(algorithm, key, signature, data) crypto.subtle.encrypt(algorithm, key, data) crypto.subtle.decrypt(algorithm, key, data) crypto.subtle.importKey(format, keyData, algorithm, extractable, keyUsages) crypto.subtle.exportKey(format, key) crypto.subtle.generateKey(algorithm, extractable, keyUsages)

Backed by internal:openssl (libcrypto via FFI). If OpenSSL is not installed, every method throws an informative error rather than crashing the process.

Registers globalThis.crypto at import time.
