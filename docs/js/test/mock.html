mock

js/test/mock.mts

fino:test/mock — scoped test doubles for runtime globals and builtins.

This module starts with fetch mocking, but the structure is intentionally generic so more scoped mocks can live here later without inventing another ad-hoc test surface.

The API is closure-scoped on purpose:

await mockFetch(async (mock) => {
  mock.get('https://example.com/data').reply(200, 'ok');
  const res = await fetch('https://example.com/data');
});

await mockFetch('https://collector.example', async (mock) => {
  mock.post('/v1/traces').header('content-type', /json/).reply(202);
});

The original global is always restored in finally, even if the callback throws or an expectation fails.
