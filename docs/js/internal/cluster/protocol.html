internal:cluster/protocol — cluster wire types and JSON codec.

All cluster messages are JSON-encoded ClusterMessage values. The codec layer is deliberately thin: encode/decode are just JSON.stringify/parse so the transport can switch to binary (QUIC, CBOR) later without changing the protocol layer.

Realm IDs use the format {nodeId}/{localHandle}, which encodes the host node for O(1) routing: extract the nodeId prefix to find the host.

Port IDs use the format {nodeId}/p-{handle} and are used for PORT_MSG routing. Each ClusterPort on the parent side has a unique portId; the SPAWN message carries parentPortId so the child relay knows where to address PORT_MSG.
