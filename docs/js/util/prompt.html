prompt

js/util/prompt.mts

fino:util/prompt — interactive command-line prompts with non-interactive defaults.

PromptSession wraps the low-level fino:tty helpers and centralizes the policy for CI or redirected input: prompts either return explicit defaults or throw instead of blocking forever.

Classes

class PromptSession {

Stateful prompt runner for text, confirm, and select questions.

import { PromptSession } from 'fino:util/prompt';

const prompt = new PromptSession();
const name = await prompt.text({ label: 'Project name', defaultValue: 'app' });
const install = await prompt.confirm({ label: 'Install dependencies', defaultValue: true });
