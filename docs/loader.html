internal:loader — JS-side module resolution and import.meta population.

Registers two callbacks with the Rust module loader via internal:loader-hooks:

  • resolve(specifier, referrerDir, root) → canonical absolute path
  • initImportMeta(importMeta, filename, root) → populates import.meta

This module must remain synchronous (no top-level await) so it can be statically imported from _main.mjs.

We open our own libc handle for realpath rather than reusing internal:file/bindings because that module uses await import(...), which would make this module (and _main.mjs) async.
