internal:cluster/transport — ClusterTransport interface.

All cluster logic depends only on this interface. Switching from WebSocket to QUIC (or any other transport) requires only a new implementation, not changes to the protocol or routing layers.

Interfaces

export interface ClusterTransport {

Readonly Propertys

readonly nodeId: string

Methods

send(to: string, msg: ClusterMessage): void

Send a message to a specific peer identified by nodeId. On seed nodes this routes directly to the peer's connection. On worker nodes this sends through the seed which routes it onward.

broadcast(msg: ClusterMessage): void

Broadcast a message to all connected peers. Seed-only: throws if called on a worker transport.

on(handler: (from: string, msg: ClusterMessage) => void): void

Register a message handler. Multiple handlers may be registered; all are called in registration order for every incoming message.

fromNodeId is the seed's nodeId for control-plane messages, or the originating nodeId embedded in data-plane messages.

close(): void

Close all connections and release resources.
